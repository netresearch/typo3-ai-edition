# Members

* [LLM Foundation (netresearch/nr-llm)](nr-llm.md) - Required member of the edition: Provider configuration, encrypted API keys, chat, translation, vision and embedding services for every other member.
* [Secrets Vault (netresearch/nr-vault)](nr-vault.md) - Required member of the edition: Envelope-encrypted storage for API keys and credentials.
* [AI Cowriter (netresearch/t3-cowriter)](t3-cowriter.md) - Required member of the edition: Writing assistant in CKEditor.
* [AI Chat (netresearch/nr-mcp-agent)](nr-mcp-agent.md) - Required member of the edition: Chat assistant in the TYPO3 backend with tool calling.
* [Landing Page Generator (netresearch/nr-landingpage)](nr-landingpage.md) - Required member of the edition: Backend wizard that drafts landing pages.
* [Content Repurpose (netresearch/nr-repurpose)](nr-repurpose.md) - Required member of the edition: Turns a page or PDF into a podcast, diagram, story or text variants.
* [LLM Compatibility Layer (netresearch/nr-llm-compat)](nr-llm-compat.md) - Suggested member of the edition: Routes the LLM calls of third-party AI extensions through nr-llm.
* [Browser AI (netresearch/nr-browser-ai)](nr-browser-ai.md) - Suggested member of the edition: On-device assistant for the current page in Chrome's built-in AI.
